WHAT WAS BEING FIXED
====================
Cards in Field Notes and AI Coaching feed navigate to /visits/:id but the visit
detail page shows "Visit not found" because the API crashes with a ZodError.

ROOT CAUSE
==========
GET /api/visits/:id returns 500 ZodError. Nullable DB columns (notes.audioUrl,
notes.durationSeconds) return null from PostgreSQL, but the Zod response schema
uses .optional() (accepts undefined, NOT null). Fix: change to .nullish().
